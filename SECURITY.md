# Security

Do not post passwords, tokens, real client records, or preference exports in issues. Report general bugs through GitHub Issues with fictional data.

For a security issue that would put user data at risk, use the repository's private vulnerability reporting feature when available. If private reporting is unavailable, open an issue requesting a private contact without disclosing exploit details or sensitive records.

TickTack stores local data in macOS application preferences and does not add application-level encryption. Your macOS account, disk encryption, and backups determine access to those files. Restorable deletions are not secure erasure.
