# Contributing

Please open an issue describing a concrete bug or proposed improvement. For bugs, include macOS version, CPU architecture, app version, language, and steps to reproduce. Use fictional data; do not upload real project notes or preference files.

For pull requests:

1. Keep changes focused and preserve existing saved data.
2. Add German and English text for new interface strings.
3. Maintain readable text and generous click targets.
4. Test changes using isolated stores: `./scripts/test.sh`.
5. Build the application with `./scripts/build.sh`.
6. Explain the resulting behavior and relevant validation.

Do not commit secrets, signing certificates, personal data, build products, or local editor state. Contributions are submitted under this repository's MIT license. No contributor license agreement is required.
