# Changelog

## 0.10.0

- Lossless `.ticktack` project exports and an option to save all projects together.
- Import previews for project files, CSV/TSV and Excel, with column mapping, decimal selection, destination projects and explicit invalid-row handling.
- Styled Excel exports with frozen headers, filters, alternating rows and a project summary.
- Paginated PDF time reports with readable rows, repeated headers, totals and continuing notes.
- Import and export commands in File, a compact export menu in the window, and explicit alternating table backgrounds.
- German/English documentation and transfer regression checks.

## 0.9.0

- Public source distribution with an MIT license, original icon, and reproducible app packaging.
- German interface for German primary system languages; English for all others.
- Project colors, menu bar timer, manual entries, live project totals, editable details, and CSV export.
- Project-scoped search, sorting, restorable deletion, and adjustable text size.
- Fresh installations start empty; no client example records are bundled.
- Automated tests with isolated preferences and a deterministic clock.
