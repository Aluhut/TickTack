# Screenshots

These screenshots show the native TickTack interface with fictional demonstration projects and entries. No client records or personal time logs are included. The sample project names, task descriptions, dates, and durations are illustrative.

- `overview-dark.jpg`: project overview and timer, dark appearance.
- `entry-details-light.jpg`: selected entry and editable inspector, light appearance.
- `new-project-dark.jpg`: project creation and accent-color selection, dark appearance.

Screenshots use the English interface. German is available in the app based on the primary system language. Demonstration data is not included in normal app installations. The screenshots are distributed under the repository's MIT license; Apple's interface elements retain their applicable rights.
