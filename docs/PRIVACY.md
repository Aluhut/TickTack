# Privacy

TickTack makes no network requests. There are no accounts, analytics, advertisements, crash uploads, or remote services.

Projects, entries, preferences, and restorable deletions are stored on your Mac through `UserDefaults`. The public application bundle uses `app.ticktack.desktop`. The operating system manages the exact preference file location.

CSV exports are written only to a location you select. Anyone you share an export with can read its project notes and time records. Deleted items remain in the local restoration history until application data is removed outside the app. Running measurements and drafts are held in memory until saved.

The source repository contains no example client data. Keep backups through your normal Mac backup process. TickTack currently provides no cloud synchronization, automatic backups, or in-app backup import.
