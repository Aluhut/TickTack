# Privacy

TickTack makes no network requests. There are no accounts, analytics, advertisements, crash uploads, or remote services.

Projects, entries, preferences, and restorable deletions are stored on your Mac through `UserDefaults`. The public application bundle uses `app.ticktack.desktop`. The operating system manages the exact preference file location.

Project files, CSV/Excel tables, and PDF reports are written only to a location you select. Imports are read locally; files are not uploaded. Anyone you share an export with can read its project notes and time records. Deleted items remain in the local restoration history until application data is removed outside the app. Running measurements and drafts are held in memory until saved.

The source repository contains no example client data. Keep backups through your normal Mac backup process. Manual `.ticktack` exports can be imported as new project copies. These files are not encrypted and do not include preferences, deletion history, running measurements, or drafts. TickTack provides no cloud synchronization or automatic backups.
