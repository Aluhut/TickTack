# First launch / Erster Start

[Deutsch](#deutsch) · [English](#english)

## Deutsch

### Warum erscheint eine Warnung?

Die GitHub-Downloads von TickTack sind derzeit nicht von Apple notarisiert. Gatekeeper kann deshalb beim ersten Start melden, dass der Entwickler nicht verifiziert oder die App nicht auf Schadsoftware geprüft werden konnte.

### TickTack gezielt freigeben

Fahre nur fort, wenn du der Quelle vertraust. Lade die App von den [offiziellen TickTack-Releases](https://github.com/Aluhut/TickTack/releases/latest).

1. Entpacke die ZIP-Datei und ziehe **TickTack.app** nach **Programme**.
2. Öffne TickTack per Doppelklick. Schließe gegebenenfalls die Warnmeldung mit **Fertig** beziehungsweise **Abbrechen**.
3. Öffne das **Apple-Menü  → Systemeinstellungen → Datenschutz & Sicherheit**.
4. Scrolle zum Abschnitt **Sicherheit**. Beim Hinweis zu TickTack klicke auf **Dennoch öffnen**.
5. Bestätige die erneute Nachfrage mit **Öffnen**, wenn du fortfahren möchtest.

macOS merkt sich diese Ausnahme für die App. Gatekeeper bleibt für andere Apps aktiv. Terminalbefehle sind nicht erforderlich.

Fehlt die Schaltfläche, versuche zuerst erneut, TickTack zu öffnen. Auf verwalteten Macs kann die IT-Abteilung die Freigabe einschränken.

Bei einer ausdrücklichen Schadsoftware- oder Beschädigungswarnung diese Anleitung **nicht** zum Umgehen verwenden. Lade eine frische Kopie herunter und melde das Problem.

[Apples offizielle Anleitung](https://support.apple.com/de-de/102445)

## English

### Why does macOS show a warning?

TickTack's GitHub downloads are not currently notarized by Apple. Gatekeeper may report that the developer cannot be verified or that Apple cannot check the app for malicious software.

### Approve TickTack individually

Continue only if you trust the source. Download the app from the [official TickTack releases](https://github.com/Aluhut/TickTack/releases/latest).

1. Extract the ZIP and drag **TickTack.app** into **Applications**.
2. Double-click TickTack. If a warning appears, dismiss it with **Done** or **Cancel**.
3. Open the **Apple menu  → System Settings → Privacy & Security**.
4. Scroll to **Security**. Next to the message about TickTack, choose **Open Anyway**.
5. Confirm the next prompt with **Open** if you want to proceed.

macOS remembers this app-specific exception. Gatekeeper remains active for other apps. No Terminal commands are needed.

If the button is missing, try opening TickTack again first. A managed Mac may restrict approval; contact its administrator.

Do **not** use these steps to override an explicit malware or damaged-app warning. Download a fresh copy and report the problem instead.

[Apple's official instructions](https://support.apple.com/en-us/102445)
